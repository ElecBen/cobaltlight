# Changelog

## 0.3.0

- contraste(): la razon de contraste entre dos colores, de 1.0 a 21.0
- mezcla(): la mezcla de dos colores; peso 0.0 devuelve `a`
- Los tests corren en GitHub Actions

## 0.2.0

- luminancia(): la luminancia relativa del color, de 0.0 a 1.0
- Type hints en la API publica
- Docstring de modulo y __all__

## 0.1.0

- a_rgb(): la tupla (r, g, b) de un color escrito en hex
- a_hex(): el color en forma #rrggbb, recortado a 0-255
- Tests con pytest
